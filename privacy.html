Privacy policy

Last updated: 23 October 2026

Who uses this app

Nikos GClient is a private, self-hosted mail client with exactly one user: its owner. It is not offered to the public and no one else can sign in.

What data it accesses

With the owner's consent, the app accesses the owner's own:

  • Gmail – to read messages, apply labels, archive messages, create drafts, and send a reply only after the owner clicks “Send it” (with a 10-second undo).
  • Google Tasks and Google Calendar – only if the owner grants these permissions in a later version: to list, add and change the owner's own tasks and events.

How the data is used and stored

  • Data is used only to provide the app's features to the owner.
  • It is processed on a server the owner operates privately. Messages are cached there in a local database; the OAuth token is stored there only, encrypted.
  • To sort messages and to suggest replies, the subject, sender and text of a message are sent to an AI model provider (OpenCode Zen). This happens only for the owner's own requests and features; the data is not used to train generalized AI models.
  • Data is not sold, shared with other third parties, or used for advertising.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time in the app (disconnect button, which also revokes the token at Google) or at myaccount.google.com/permissions.
