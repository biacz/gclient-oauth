Privacy policy

Last updated: 24 October 2026

Who uses this app

Nikos GClient is a private, self-hosted mail client with exactly one user: its owner. It is not offered to the public and no one else can sign in.

What data it accesses

With the owner's consent, the app accesses the owner's own:

  • Gmail – to read messages, apply labels, archive messages, create drafts, and send a reply only after the owner clicks “Send it” (with a 10-second undo).
  • Google Tasks and Google Calendar – only if the owner grants these permissions: to list, add, change and delete the owner's own tasks and events, and to list the owner's calendars. Events are written without guests, so the app never sends invitations.

How the data is used and stored

  • Data is used only to provide the app's features to the owner.
  • It is processed on a server the owner operates privately. Messages are cached there in a local database; the OAuth token is stored there only, encrypted. Tasks and events are read live from Google and not stored, apart from a link between a task or event and the message it was made from.
  • To sort messages, to suggest replies and to suggest tasks and events found in a message, the subject, sender and text of a message are sent to an AI model provider (OpenCode Zen). Short notes the owner types to create a task or event are sent there too. The owner's tasks and calendar events themselves are not sent. This happens only for the owner's own requests and features; the data is not used to train generalized AI models.
  • Data is not sold, shared with other third parties, or used for advertising.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time in the app (disconnect button, which also revokes the token at Google) or at myaccount.google.com/permissions.
